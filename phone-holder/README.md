# Galaxy S23 Ultra 椅背手机架

座面要放电脑，所以**手机不能挂在座面这一侧**。v2 把手机放在**椅背上缘的上方**，向后倾 15°，座面上方一点都不占用。

## v2「上缘站立式」（推荐）

| 文件 | 说明 |
|---|---|
| `stl/s23ultra_perch_portrait_print.stl` | 竖屏版，约 85 × 63 × 213 mm，约 23 g |
| `stl/s23ultra_perch_landscape_print.stl` | 横屏版（看视频），约 170 × 41 × 131 mm，约 29 g |
| `s23ultra_holder.blend` | Blender 文件（单位 mm），含半透明手机和椅背做配合检查 |
| `images/perch_*.png` | 预览：手机 + 椅背 |

**怎么不挡电脑**
- 夹在椅背上的只有两片薄脚，座面这一侧的脚只有 4 mm 厚、36 mm 长，贴着椅背。
- 手机在椅背上缘**之上**，不会伸进座面空间，电脑可以直接放在坐垫上。
- 底托比椅背前面多出约 17–21 mm，只在椅背上缘上方。如果电脑屏幕比椅背高、会顶到，用 `--rise` 把手机抬高，或把 `--tilt` 调小。

**怎么好拿好放**
- 手机向后倾 15°，靠重力就稳，不需要卡扣。
- 侧挡边只有下面 34 mm，侧壁只有 48 mm，**手机直接往上提就出来，往下放就到位**，一只手就行；捏手机两侧上半部分拿。
- 竖屏版底托中间是空的：手指可以从下面顶，充电线、喇叭、S Pen 也都不挡。
- 横屏版右侧只留下半截挡板，USB‑C 可以一边充电一边看。
- 夹子留在椅背上不用拆，拿手机时不会带起夹子（毛毡垫提供摩擦力）。

### 先量两个尺寸

1. **椅背上缘厚度**（默认按 18 mm 估的，务必用游标卡尺量）。
2. （可选）电脑屏幕上沿比椅背上缘高多少，用来决定 `--rise`。

```bash
pip install manifold3d numpy matplotlib bpy
python3 make_holder.py --rail 16.5                 # 椅背厚度
python3 make_holder.py --rail 16.5 --case 3        # 手机带壳
python3 make_holder.py --rail 16.5 --rise 40       # 手机再抬高 40 mm
python3 make_holder.py --rail 16.5 --tilt 10       # 后倾角度
python3 make_blend.py  --rail 16.5                 # 重新生成 .blend
```

槽宽 = 椅背厚度 + 1.6 mm。

### 防刮垫

夹子两片脚内侧各有一个 30 mm 宽的凹槽（0.8 mm 深），贴 **1.3 mm 厚自粘毛毡/EVA 垫**，比凹槽凸出 0.5 mm，夹紧椅背也不刮木面。

### 打印（Bambu Lab）

- PETG，0.2 mm 层高，3 圈墙，15% 填充。
- 导入后**不用旋转**（已侧躺），夹子部分不需要支撑。手机槽有一面侧壁悬空，打开 **树状支撑**。
- 竖屏版最长约 213 mm，需要 256 mm 的热床（X1 / P1 / A1），A1 mini 放不下。

### 使用

- 夹子扣上椅背，手机放进槽里。想换到椅背另一面，把支架转 180° 再扣（左右对称）。
- 手机尺寸：163.4 × 78.1 × 8.9 mm（三星官方规格）。摄像头区域背板开了窗口避让。
- 电源/音量键窗口位置是按常见位置估的，如果不对可改 `make_holder.py` 里的 `top_off` 和 `btn_len`。

### Blender

`s23ultra_holder.blend`：`Holders` 是印刷用模型，`Fit check` 是半透明手机和椅背（导出 STL 前先隐藏）。模型是已合并的网格，不是参数化的；要改尺寸请用上面的命令重新生成。

## v1「挂在椅背前面」（不推荐，会挡到座面）

`stl/s23ultra_holder_*_print.stl`：手机吊在椅背下方，会占用座面上方的空间，保留仅供参考。

## 文件

- `make_holder.py`：参数化生成 v1 / v2 的 STL 和预览图。
- `make_blend.py`：生成 `.blend`（`--render` 可额外输出 Blender 预览，需要 EGL/GPU 库）。
