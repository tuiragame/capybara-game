# Galaxy S23 Ultra 椅背挂钩手机架

挂在椅背上缘的 3D 打印手机架。上面是一个倒 U 型挂钩，下面是可从上方滑入的手机槽。

| 文件 | 用途 |
|---|---|
| `stl/s23ultra_holder_portrait_print.stl` | 竖屏版（手机竖放，232 × 42 × 85 mm，已侧躺摆好） |
| `stl/s23ultra_holder_landscape_print.stl` | 横屏版（看视频，147 × 47 × 170 mm，已侧躺摆好） |
| `make_holder.py` | 参数化脚本，改尺寸后重新生成 |
| `images/*.png` | 预览图（挂着的方向） |

## ⚠️ 先量一下椅背厚度

椅背厚度是我从照片估的 **18 mm**。用游标卡尺量椅背上缘（挂钩夹住的位置），然后：

```bash
pip install manifold3d numpy matplotlib
python3 make_holder.py --rail 16.5      # 换成你量到的厚度
python3 make_holder.py --rail 16.5 --case 3   # 如果手机带壳，再加 case 余量
```

槽宽 = 椅背厚度 + 1.6 mm。

## 防刮垫

挂钩内侧两面各有一个 30 × 24–30 mm、0.8 mm 深的凹槽，贴 **1.3 mm 厚的自粘毛毡/EVA 垫**。垫子会比凹槽凸出 0.5 mm，夹紧椅背，也不会刮伤胡桃木面。

## 打印建议（Bambu Lab）

- 材料：PETG（或 PLA+），0.2 mm 层高，3 圈墙，15% 填充。
- 直接导入，**不用旋转**：零件已经侧躺，挂钩不需要支撑。
- 手机槽的一侧挡边悬空，需要打开 **树状支撑**。
- 大约 25–30 g。

## 使用

- 手机从上方滑入，两侧 2.2 mm 的挡边抓住屏幕边缘。
- **竖屏版**：底部中间留空（USB‑C / 喇叭 / S Pen），右侧留出电源和音量键窗口。
- **横屏版**：手机逆时针转 90°，按键朝上（开口），USB‑C 在右侧，右侧挡板只保留下半截，充电线可以接。
- 零件左右对称。挂在椅背**哪一面**，手机就在哪一面；想换面，把整个支架转 180° 再挂。
- 支架和椅背之间留了 3 mm（竖屏）/ 8 mm（横屏）的间隙，椅背是弧形的也不会顶到。可以用 `--gap` 调整。

## 尺寸来源

Galaxy S23 Ultra：163.4 × 78.1 × 8.9 mm（三星官方规格）。摄像头在背面，背板开了大窗口避让。
电源/音量键窗口的位置是按常见位置估的（距顶部 25–105 mm），如果不对可改 `make_holder.py` 里的 `top_off` 和 `btn_len`。

## Blender

`s23ultra_holder.blend` を Blender（4.x / 5.x）で開くだけで使えます。単位は mm（1 BU = 1 mm）。

- `Holders` コレクション：印刷用メッシュ（竖屏 / 横屏）。椅子に掛けた向き（背もたれ上端が Z=0、スマホ側が −Y）。
- `Fit check` コレクション：半透明の S23 Ultra と背もたれの板。フィット確認用なので、STL を書き出す前に非表示にしてください。
- 椅子の厚さ・ケース有無を変えて作り直す：`pip install bpy manifold3d numpy` → `python3 make_blend.py --rail 16.5 --case 3`
- メッシュはブーリアン適用済み（パラメトリックではない）です。寸法を変えるなら上のコマンドで再生成するのが確実で、Blender 内では Sculpt / Edit Mode で微調整できます。
