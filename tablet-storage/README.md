# XPPen Deco Pro LW (Gen 2) 竖立收纳座 (无盖)

平板 / 快捷键遥控器 (ACK05) / 数位笔 全部竖着插, 占地约 **120 × 72 mm**, 高 126 mm (含绕线塔)。

| 文件 | 说明 |
|---|---|
| `deco_pro_lw_gen2_storage.3mf` | 完整版, 直接导入 Bambu Studio |
| `deco_pro_lw_gen2_storage_fit_test.3mf` | 试配版 (16 mm 高), 先打这个确认槽宽 |
| `build_storage_box.py` | 参数化生成脚本 (`pip install manifold3d trimesh numpy`) |
| `preview.png` | 预览图 |

## 尺寸 (mm)
- 平板槽: 宽 12.4 (平板厚 10.66), 深 36, 两端贯通 — 平板 333 mm 长边朝下, 左右悬出
- 遥控器槽: 14.0 × 76.0, 深 40 — 短边 (平坦一侧) 朝下, 转盘朝上
- 绕线塔 (后排右侧, 70 × 26 长圆形立柱): 左端圆头内是笔孔 Ø20 深 90, 笔尾朝下、笔尖朝上
- 传输线: 绕在塔外 75 mm 高的绕线区, 顶部有 4 mm 挡边防滑脱; 两条各约 1.5 m (线径 ≤ 4.5 mm) 可叠绕。线绕出的厚度已预留, 不会碰到平板
- U 盘槽 (笔塔左侧): 26 × 14, 深 12 — 一般 U 盘 / 无线接收器竖着插, 约露出 2/3, 好拿取

## 建议切片设置 (P1S)
PLA 或 PETG, 0.20 mm, 4 层墙, 15% 填充, 不需要支撑。模型已居中放在热床上。
